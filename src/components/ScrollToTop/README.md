# ScrollToTop 組件使用說明

## 🎯 問題描述

在 React Router 應用程式中，當用戶從一個頁面導航到另一個頁面時，瀏覽器默認不會自動滾動到頁面頂部。這會導致用戶在查看新頁面時可能停留在之前的滾動位置，影響用戶體驗。

## ✅ 解決方案

`ScrollToTop` 組件會在每次路由變更時自動將頁面滾動到頂部，確保用戶總是從頁面開始位置查看新內容。

## 🛠️ 實作內容

### 1. ScrollToTop 組件

- **位置**: `src/components/ScrollToTop/ScrollToTop.js`
- **功能**: 監聽路由變更，自動滾動到頁面頂部
- **特色**:
  - 支援錨點鏈接（不會覆蓋錨點滾動行為）
  - 使用 `setTimeout` 確保頁面完全渲染後才滾動
  - 立即滾動（無動畫）避免閃爍

### 2. 整合到 App.js

組件已整合到主應用程式中：

```jsx
<ErrorBoundary>
  <ScrollToTop />
  <div className="App">{/* 其他組件 */}</div>
</ErrorBoundary>
```

## 🧪 測試方法

### 方法一：手動測試

1. 訪問首頁並滾動到頁面底部
2. 點擊導航選單中的任何鏈接
3. 確認新頁面從頂部開始顯示

### 方法二：使用測試組件

1. 訪問 `/scroll-test`（如果有添加到路由）
2. 查看開發者工具 Console 中的滾動位置信息
3. 測試不同路由間的切換行為

### 方法三：瀏覽器開發者工具

1. 開啟開發者工具 (F12)
2. 在 Console 中執行：
   ```javascript
   console.log("當前滾動位置:", window.scrollY);
   ```
3. 切換頁面後再次檢查滾動位置

## 📋 預期行為

### ✅ 正常情況

- **頁面切換**: 從任何頁面導航到其他頁面時，新頁面從頂部開始顯示
- **文章詳細頁**: 從部落格列表點擊文章時，文章頁面從頂部開始顯示
- **分類切換**: 在部落格頁面切換分類時，頁面滾動到頂部

### 🚫 不影響的情況

- **錨點鏈接**: URL 包含 `#` 的鏈接仍會正常滾動到對應錨點
- **同頁面內操作**: 不會影響頁面內的平滑滾動或其他滾動行為

## 🔧 自訂設定

如果需要自訂滾動行為，可以修改 `ScrollToTop.js` 中的設定：

```javascript
window.scrollTo({
  top: 0,
  left: 0,
  behavior: "smooth", // 改為平滑滾動
});
```

或添加條件判斷：

```javascript
// 只在特定路由生效
if (pathname.startsWith("/blog/")) {
  window.scrollTo({ top: 0, left: 0, behavior: "instant" });
}
```

## ⚠️ 注意事項

1. **效能影響**: 組件使用 `useEffect` 監聽路由變更，對效能影響極小
2. **兼容性**: 適用於所有現代瀏覽器
3. **錨點支援**: 自動檢測並保留錨點鏈接的原始行為
4. **時機控制**: 使用 `setTimeout` 確保在 DOM 更新後執行滾動

## 🚀 預期改善效果

實施 ScrollToTop 組件後：

- ✅ 用戶體驗提升：每次頁面切換都從內容開始位置查看
- ✅ 導航流暢性：消除頁面切換時的位置混亂
- ✅ 符合網頁慣例：與傳統網頁導航行為一致
- ✅ 無副作用：不影響現有功能和樣式

這個解決方案應該完全解決您提到的「文章點選後不會從最上方開始顯示」的問題。
