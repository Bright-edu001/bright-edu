## 1. 登入後台

1. 開啟瀏覽器，輸入後台網址（請向管理員索取）。
2. 輸入您的帳號與密碼，點擊「登入」。

---

## 2. 主要功能介紹

登入後，您會看到左側選單，包含：

- 文章管理
- 新聞管理
- 招生資訊管理
- 儀表板（總覽）
- 登出

## 3. 文章管理

- 點選「文章管理」可查看所有文章列表。
- 新增文章：點擊「新增文章」按鈕，選擇文章類型後進入對應編輯器，填寫完成後點「儲存」。
- 編輯文章：在列表中找到要編輯的文章，點擊「編輯」按鈕，修改內容後儲存。
- 刪除文章：點擊「刪除」按鈕即可移除。

### 文章類型與對應編輯器

新增文章時會出現類型選擇視窗，請依內容性質選擇：

| 類型         | 編輯器                 | 適用情境                                   |
| ------------ | ---------------------- | ------------------------------------------ |
| **最新消息** | 所見即所得 (BlockNote) | 校園新聞、排名公告、一般圖文文章           |
| **招生資訊** | 結構化表單             | 招生截止日期、申請期限、學期資訊等多層資料 |

### 共用欄位（兩種類型皆有）

| 欄位                | 說明                                 |
| ------------------- | ------------------------------------ |
| 標題                | 文章主標題                           |
| 摘要                | 列表頁顯示的短描述                   |
| 分類 (category)     | `news` 或 `enrollment`，影響首頁篩選 |
| 排序 (order)        | 數字越小排越前面                     |
| 圖片 URL / 縮圖 URL | 封面圖路徑                           |
| 圖片寬度 / 高度     | 封面圖原始尺寸（px），預設 1000×571  |

> **注意**：文章儲存後系統會自動產生 `/blog/{id}` 連結，無需手動填寫。

## 4. 最新消息編輯器（BlockNote 所見即所得）

最新消息類型文章使用 **BlockNote** 富文字編輯器，支援：

- **標題**：H1 / H2 / H3 三級標題
- **段落**：一般文字段落
- **項目符號清單 / 有序清單**：自動縮排階梯式排版
- **圖片**：直接插入圖片 URL
- **文字樣式**：粗體、斜體、底線等

操作方式：在編輯區直接輸入，使用工具列或 `/` 斜線指令插入各種區塊。

## 5. 招生資訊編輯器（結構化表單）

招生資訊類型文章使用結構化表單，用於建立多層巢狀的招生資料（如申請截止日期、開課日期、領域清單等）。

### 架構說明

文章由多個「資訊區塊」組成，每個區塊代表一個學期或入學批次：

```
文章
└── 資訊區塊（如 Spring 2026 春季班）
    ├── 區塊標題（如 Spring 2026 春季班資訊）
    ├── 旗幟圖片（可選）
    └── sections（段落列表）
        └── 段落（如 ✅ 開課日期）
            └── items（子項目，如 → MBA：Jan/12/2026）
                └── subItems（孫項目，如 📖 MBA開課領域:）
                    └── list（清單，如 Management 管理學領域）
```

### 新增/編輯方式

1. 點擊「＋ 新增資訊區塊」加入學期
2. 填寫區塊標題，可上傳旗幟圖片 URL
3. 點擊「＋ 新增段落」，選擇圖標（✅ check / → arrow / 📖 book），填寫文字
4. 若段落有子項目（如 MBA/MS 日期），點擊段落內「＋ 新增子項目」
5. 子項目若要再附清單，點擊「＋ 新增孫項目」並填寫 list

## 6. 常見問題

**Q: 編輯完內容要如何儲存？**
A: 點擊「儲存」或「送出」按鈕，系統會自動保存。

**Q: 如何新增段落或子項目？**
A: 在編輯頁面下方有「新增段落」或「新增子項目」按鈕，點擊即可。

**Q: 文章連結（URL）要怎麼設定？**
A: 不需要手動設定。儲存後系統會自動產生 `/blog/{文章ID}` 格式的連結。

**Q: 最新消息和招生資訊的差別？**
A: 最新消息用所見即所得編輯器，適合圖文並茂的文章；招生資訊用結構化表單，適合多層巢狀的申請資訊。

**Q: 圖片寬度/高度填什麼？**
A: 填入圖片的原始尺寸（像素），系統用來計算比例，預設為 1000×571。

**Q: 忘記密碼怎麼辦？**
A: 請聯絡系統管理員協助重設。
